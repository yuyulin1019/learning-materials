# 韓文入門：第一次見面，介紹自己

對象：韓文初學者。

目的：認識禮貌問候與以身分介紹自己的基本句型。

來源：[世宗學堂韓語基礎文法：自我介紹](https://nuri.iksi.or.kr/practice/koreanBasicGrammar/01/index_kor.html)。以下內容自行整理，練習為自編。

1. 對話：안녕하세요? 저는 학생이에요. 你好，我是學生。
2. 單字：안녕하세요 你好；저는 我（作為主題）；학생 學生。
3. 名詞接 이에요／예요 表示「是」：有收尾子音接 이에요，沒有接 예요。학생이에요；의사예요（是醫生）。
4. 練習：學生後面該接哪一個？答案是 이에요，因為 생 有收尾子音 ㄴ。
